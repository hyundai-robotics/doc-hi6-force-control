## 5.3 접촉면 판단 기능 

다음은 로봇에서 **접촉면 판단 기능**을 사용하는 Job 프로그램 예시입니다.  

---

##### **동작 개요** 

**설정**에서 **contact check** 조건을 아래와 같이 설정 합니다. 

- 예시: 5초 동안 아래 기준으로 접촉을 유지하면, 접촉면 판단 OK

| 항목             | 설정 값 |
|------------------|---------|
| 힘 오차           | 3 N |
| 힘 방향 변화량      | 20 deg |
| 접촉 각도         | 40 deg |
| 유지 시간             | 5 sec |


---

##### **JOB 프로그램 예시**  

```python
delay 1.0                            # 제어 시작 전 안정화 대기
fctrl on,cnd=1                       # 힘 제어 시작 (설정 번호 1 사용)
delay 0.5                            # 접촉면 판단 조건 실행 전 까지 0.5초 대기 

wait _fctrl.contact, 20              # 접촉면 판단 조건 실행, 접촉면 판단 OK 까지 대기, 최대 20초 까지 검사 진행 

fctrl off                            # 힘 제어 종료
