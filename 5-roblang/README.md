# 5. 명령어

이 문서는 힘 제어 기능과 관련된 주요 시스템 명령어 및 상태 변수(시스템 변수)에 대한 설명을 제공합니다. 각 명령어는 힘 제어 설정, 동작 제어, 상태 확인 및 F/T 센서 데이터 수신에 사용됩니다.

---

##### **1. 명령어 (V70.02-00 이상)**

V70.02-00 이상 버전에서는 명확한 구분을 위해 실행 명령어(`fctrl`)와 내장 상태 변수(`_fctrl`)가 분리된 표준 형식을 사용합니다.

##### **[명령어]**

| 명령어 | 설명 | 인자 (Argument) | 비고 |
| :--- | :--- | :--- | :--- |
| `fctrl on, cnd=` | 힘 제어 구동을 시작하고 지정된 제어 조건을 적용합니다. | `cnd=설정 번호` (예: `cnd=1`) | 힘 제어 시작 시 필수 실행 |
| `fctrl control, cnd=` | 힘 제어 구동을 유지한 상태에서 제어 파라미터 조건만 실시간으로 변경합니다. | `cnd=설정 번호` (예: `cnd=2`) | 모션 정지 없이 제어 조건 전환 시 사용|
| `fctrl off` | 힘 제어 구동을 안전하게 종료하고 일반 위치 제어로 복귀합니다. | 없음 | - |
| `fctrl motion_on` | 지정된 자동 경로 생성 모션(Spiral, Bidir, Unidir)을 시작합니다. | 없음 | `fctrl on` 상태에서만 동작 유효 |
| `fctrl motion_off` | 구동 중인 자동 경로 생성 모션을 즉시 중지합니다. | 없음 | 힘 제어(`fctrl on`) 상태는 유지됨 |

{% hint style="info" %}

**`fctrl control` 변경 가능 파라미터(사양):** 해당 명령어로 실시간 조건을 전환할 때는 제어 조건(선택 축, 활성 여부, 목표 힘, 응답성, 댐핑 가인, 제한 속도, $\pm$ 위치 제한 범위)만 변경할 수 있습니다. 기준 좌표계, 툴 번호 및 필터링/프로파일/모션 설정은 변경되지 않고 기존에 설정된(`fctrl on, cnd`) 설정을 유지 합니다. 

{% endhint %}

##### **[모니터링 관련 시스템 변수]**

| 시스템 변수 | 설명 | 데이터 타입 | 비고 |
| :--- | :--- | :--- | :--- |
| `_fctrl.motion` | 현재 자동 경로 생성 모션의 구동 상태를 반환합니다. | (0: 구동 중, 1: 모션 완료) | 모션 동작 상태 여부 확인(ex: `wait _fctrl.motion==0`) |
| `_fctrl.contact` | 현재 작업 대상물 표면과의 접촉 판단 상태를 반환합니다. | (0: 미접촉, 1: 접촉 완료) | 접촉 조건 충족 여부 확인(ex: `wait _fctrl.contact`) |
| `_fctrl.force_x` | 현재 F/T 센서가 측정 중인 툴 좌표계 기준 X축 방향의 힘을 수신합니다. | (단위: N) | - |
| `_fctrl.force_y` | 현재 F/T 센서가 측정 중인 툴 좌표계 기준 Y축 방향의 힘을 수신합니다. | (단위: N) | - |
| `_fctrl.force_z` | 현재 F/T 센서가 측정 중인 툴 좌표계 기준 Z축 방향의 힘을 수신합니다. | (단위: N) | 가압 제어축 모니터링 주요 변수 |
| `_fctrl.torque_rx` | 현재 F/T 센서가 측정 중인 툴 좌표계 기준 X축 회전 토크를 수신합니다. | (단위: Nm) | - |
| `_fctrl.torque_ry` | 현재 F/T 센서가 측정 중인 툴 좌표계 기준 Y축 회전 토크를 수신합니다. | (단위: Nm) | - |
| `_fctrl.torque_rz` | 현재 F/T 센서가 측정 중인 툴 좌표계 기준 Z축 회전 토크를 수신합니다. | (단위: Nm) | - |

##### **2. 명령어 (V70.02-00 미만)**

V70.02-00 미만 하위 버전의 제어기기 및 레거시 프로그램 코드에서는 아래의 전역 변수 및 내장 함수 규격을 사용하므로 유지보수 시 주의하시기 바랍니다.

| 명령어 / 함수 | 설명 | 인자 및 세부 규칙 | 비고 |
| :--- | :--- | :--- | :--- |
| `motion_state` | 현재 자동 경로 생성 모션의 구동 상태를 반환합니다. | 없음 | V70.02-00 버전의 `_fctrl.motion`과 동일 |
| `contact_state` | 현재 작업 대상물 표면과의 접촉 판단 상태를 반환합니다. | 없음 | V70.02-00  버전의 `_fctrl.contact`과 동일 |

##### 3. F/T 센서 값 수신 함수

모든 소프트웨어 버전에서 호환되는 데이터 수신 함수입니다.

| 명령어 / 함수 | 설명 | 인자 및 세부 규칙 | 비고 |
| :--- | :--- | :--- | :--- |
| `cfo(crd, type)` | 지정된 좌표계 기준의 F/T 센서 데이터를 수신합니다. | `crd` : 힘 제어 조건(cnd)에 설정된 기준 좌표계 번호<br>`type` : `"sensor"` 고정 | 하단 주의 사항 참조 |


---

{% hint style="info" %}

**`cfo()` 사용 주의:** 입력한 좌표계(`crd`)가 현재 적용 중인 힘 제어 조건(`cnd`)의 기준 좌표계와 다르면 데이터가 갱신되지 않으며, 실시간 데이터 수신을 위해 `type` 인자는 반드시 소문자 `"sensor"`로 입력해야 합니다.

**사용 권장:** 인자 매칭 오류가 없는 **V70.02-00 이상의 전용 시스템 변수(`_fctrl.force_x` 등)** 사용을 강력히 권장합니다.

{% endhint %}
