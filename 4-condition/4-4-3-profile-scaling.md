### 4.4.3 프로파일 : 힘/토크 스케일링

F/T 센서 데이터가 특정 크기 이하일 때는 힘 제어 루프가 반응하지 않도록 차단하고, 임계값을 넘어서면 원래의 목표 제어선까지 부드러운 곡선(Smooth Curve) 혹은 단차선 형태로 연결시켜 전반적인 접촉 안정성을 높입니다.

[F2: 시스템] ➔ [4: 응용 파라미터] ➔ [24: 힘 제어] ➔ [3: 힘 제어 옵션] ➔ **[Profile] 탭 선택**

---

![](../_assets/_11_fctrl_ctrl_smooth_scaling.png)

##### **[주요 설정 항목]**

| 설정 항목 | 설명 |
| :--- | :--- |
| **기능 활성화** | 기능 사용 여부를 체크 박스로 지정합니다. |
| **힘 범위 - 시작 [N]** | 데드존이 적용되는 하한값입니다. 이 값 이하의 측정값은 `0 N`으로 출력됩니다. |
| **힘 범위 - 종료 [N]** | 원래 데이터와 1:1로 동기화되는 상한값입니다. 이 값 이상의 측정값은 보정 없이 그대로 출력됩니다. |
| **토크 범위 - 시작 [Nm]** | 데드존이 적용되는 하한값입니다. 이 값 이하의 측정값은 `0 Nm`로 출력됩니다. |
| **토크 범위 - 종료 [Nm]** | 원래 데이터와 1:1로 동기화되는 상한값입니다. 이 값 이상의 측정값은 보정 없이 그대로 출력됩니다. |

---

##### **[동작 예시를 통한 이해]**

<br> 

###### **스케일링 (시작 < 종료)**
* **설정 예시:** 시작 `5 N` / 종료 `15 N`

![](../_assets/_12_fctrl_ctrl_scaling_graph.png)

* **동작 분석:**
  
  A. **5 N 이하:** 데드존이 적용되어 미세 노이즈 및 진동을 차단하기 위해 `0 N`으로 출력됩니다.
  
  B. **5 ~ 15 N:** 데이터가 급격히 튀지 않도록 부드러운 곡선(Smooth Curve) 형태로 보간하여 출력됩니다.
  
  C. **15 N 이상:** 필터링 없이 원본 센서 값 그대로(1:1 선형) 제어 루프에 반영됩니다.

---

###### **계단형 스케일링 (시작 ≥ 종료)**
* **설정 예시:** 시작 `5 N` / 종료 `0 N` (시작 값이 종료 값보다 크거나 같을 때)

![](../_assets/_13_fctrl_ctrl_scaling_threshold_graph.png)

* **동작 분석:**

  A. **5 N 미만:** 측정값이 임계치에 도달하기 전이므로 `0 N` 처리됩니다.
  
  B. **5 N 이상:** 기준 만족 즉시 원본 데이터 선으로 점프(Step)하며, 이후에는 원본 값 그대로 출력됩니다.

---

{% hint style="info" %}

**모드 자동 전환:** [시작] 값이 [종료] 값보다 크거나 같으면 곡선 보간 없이 `데드존` 모드로 동작합니다.

**현장 튜닝 팁:** 로봇 진동이나 외부 흔들림으로 인한 센서 노이즈를 차단하려면, **[시작] 값을 노이즈 최대 실측치보다 약간 높게 설정**하여 데드존을 확보하십시오.

{% endhint %}
