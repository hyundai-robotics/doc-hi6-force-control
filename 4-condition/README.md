## 4. 힘 제어 옵션 

힘 제어 공정의 품질과 시스템 안정성을 향상시키기 위해, 작업 조건에 맞춰 센서 신호를 가공하고 로봇의 응답 및 거동 제어 방식을 세부적으로 설정하는 메뉴입니다. 

기본적인 힘/토크 제어 설정 외에도 노이즈 필터링, 프로파일, 접촉 조건 판단 및 자동 경로 생성 등의 고급 제어 옵션을 제공합니다.

**주의 사항:** 힘 제어 옵션의 개별 파라미터는 상호 의존적입니다. 초기 튜닝 시에는 로봇의 구동 속도 제한을 낮게 설정한 상태에서 필터 및 프로파일 성능을 확인하며 점진적으로 최적값을 설정하십시오.
