### 4.5.1 모션 : 접촉 조건

힘 제어 구동 시, 로봇 툴 끝단(TCP)이 작업 대상물의 표면에 안정적으로 접촉(안착)했는지를 실시간으로 감지하고 판단하는 기능입니다.

[F2: 시스템] ➔ [4: 응용 파라미터] ➔ [24: 힘 제어] ➔ [3: 힘 제어 옵션] ➔ **[Motion] 탭 선택**

---


![](../_assets/_12_fctrl_ctrl_cnd_motion_contact.png)


#### **주요 설정 항목**

아래 설정된 4가지 조건이 모두 충족되었을 때 시스템은 '접촉 완료' 상태로 판정 합니다. 

| 설정 항목 | 설명 |
| :--- | :--- |
| **힘 임계값 [N]** | 접촉을 인정하기 위한 최소 인가 힘(Force) 기준입니다. |
| **각도 변화 임계값 [각도]** | 초기 접촉 순간에 발생하는 힘 벡터 방향의 순간 변화량(변동 폭) 허용치입니다. |
| **기울기 각도 임계값 [각도]** | 작업 표면의 경사도나 툴의 기울어짐 상태에서 안정적인 접촉을 판별하기 위한 힘 벡터의 각도 허용 한계입니다. |
| **지속 시간 [초]** | 위 3가지 임계 조건(힘, 각도 변화, 기울기 각도)이 모두 만족하고 연속적으로 유지되어야 하는 최소 시간입니다. |

---

#### **설정 예시** 

* **동작 거동:** 아래 조건들이 **3초 동안 동시에 만족**하면 접촉면 안착으로 최종 판단합니다.

| 설정 항목 | UI 설정 값 | 거동 판정 기준 |
| :--- | :--- | :--- |
| **힘 임계값** | `3 N` | F/T 센서에 감지되는 외력이 3 N 이상 도달 시 |
| **각도 변화 임계값** | `10 deg` | 접촉 시 힘 방향의 순간 변화가 10° 이내로 안정화될 시 |
| **기울기 각도 임계값** | `20 deg` | 목표 각도 대비 힘 벡터의 경사 궤적이 20° 이내일 시 |
| **지속 시간** | `3 초` | 위의 상기 상태가 3초간 중단 없이 유지될 시 |

---

{% hint style="info" %}

**좌표계 설정 규칙:** 접촉 조건 알고리즘은 툴의 거동 방향과 분력을 정밀하게 매칭해야 하므로, 반드시 기준 좌표계가 **툴 좌표계(Tool Coordinate System)** 로 지정된 상태에서 정상 작동합니다.

**현장 튜닝 팁:** 로봇이 접촉 후 다음 모션으로 넘어가지 못하고 멈춰 있다면, 부딪힐 때의 충격이나 표면 굴곡 때문일 가능성이 높습니다. 이 경우 **[각도 변화 임계값]** 과 **[기울기 각도 임계값]** 을 각각 5°~10° 정도 늘려 주면 정상 동작합니다.

{% endhint %}
