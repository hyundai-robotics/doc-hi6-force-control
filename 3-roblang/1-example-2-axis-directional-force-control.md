## 3.1 예제: Z축 방향 힘 제어 

다음은 로봇에서 **센서 기반 힘 제어 기능**을 사용하는 Job 프로그램 예시입니다.  
이 예제는 **Z축 방향으로 가해지는 외력이 35N 이상**이 될 때까지 대기한 후,  
작업을 수행하는 구조로 설계되어 있습니다.

<br>

---

### **동작 개요**

- delay 명령어를 통해 힘 제어 시작 전에 시간을 확보하면,  
- 센서 노이즈나 초기 진동이 억제되어 보다 안정적인 힘 제어가 가능합니다.

- cfo 명령어에서 좌표계 선택시,  
- 힘 제어 설정 선택한 좌표계와 동일 해야 힘 정보를 수신할수 있습니다.

<br>

---

### **JOB 프로그램 예시** 

```python
delay 1.0                           # 제어 시작 전 안정화 대기
fctrl on,cnd=2                      # 힘 제어 시작 (설정 번호 2 사용)
delay 0.5

#get_current_force
var force = cfo("tool", "sensor")   # 현재 툴 기준 외력 정보 수신

# 조건 반복: Z축 외력이 35N 이상 될 때까지 대기
if abs(force.z) < 35 then *get_current_force
delay 5                             # 외력 안정화 대기
fctrl off                           # 힘 제어 종료
