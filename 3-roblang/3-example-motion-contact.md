## 3.3 示例：接触表面检测

以下是使用机器人**接触表面检测**功能的作业程序示例。

<br>

---

### **操作概述**

在**设置**中配置**接触检查**条件如下：

- **标准**：如果根据以下标准保持接触5秒，则确认接触表面检测（OK）。

| 项目 | 值 |
|------------------|---------|
| 力误差（阈值） | 3 N |
| 力方向变化（偏差角度） | 20 度 |
| 接触角度（倾斜角） | 40 度 |
| 确认时间 | 5 秒 |

<br> 

---

### **作业程序示例** 

```python
delay 1.0                           # 在开始控制之前等待稳定
fctrl on, cnd=1                     # 开始力控制（使用条件集 No. 1）
delay 0.5                           # 在执行接触检测之前等待 0.5 秒

wait contact_state()                # 执行接触检测；等待直到“OK”

fctrl off                           # 结束力控制
