# 7. 에러 및 트러블슈팅

힘 제어 공정 중 제어기 및 F/T 센서단에서 발생하는 주요 예외 상황(에러 코드)의 원인과 현장 조치 가이드입니다.

---

##### 힘 제어 예외 상황 및 대응 가이드

| 에러 코드 | 에러 명칭 및 주요 원인 | 현장 조치 가이드 |
|:--:|---|---|
| **E0260** | **힘 제어 기능 비활성화**<br>시스템 파라미터 내 힘 제어 사용 설정이 꺼져 있는 경우 | [시스템 ➔ 응용 파라미터 ➔ 힘 제어] 메뉴에서 기능 사용 설정을 **On**으로 전환하십시오. |
| **E0355** | **힘 제어 툴(Tool) 번호 오류**<br>현재 로드된 툴 번호 정보가 없거나 힘 제어 조건(`cnd`) 내 지정된 툴 설정이 불일치할 때 | 현재 티칭 프로그램에 유효한 툴 번호가 정의되어 있는지 확인하고, 힘 제어 설정 내 툴 파라미터를 재지정하십시오. |
| **E1336** | **사용자 좌표계 번호 오류**<br>힘 제어 조건(`cnd`)의 기준 좌표계가 존재하지 않는 사용자 좌표계로 지정되었을 때 | 선택한 사용자 좌표계 번호가 정상적으로 설정 및 기록되어 있는지 [좌표계 설정] 메뉴에서 검증하십시오. |
| E0259 | FT 센서 통신 문제 | 센서/케이블 점검 |
| E0272 | 지원되지 않는 센서 | 고객센터 문의(센서 IF 필요) |
| E0273 | FT 센서 통신 문제 | 센서/케이블 점검 |
| E0274 | FT 센서 통신 문제 | 센서/케이블 점검 |


* **시스템 보호 거동:** 상기 모든 예외 상황 발생 시 로봇은 즉각 가압 구동을 중단하고 **안전 일시정지(Safe-Stop)** 상태로 전환됩니다.

---

##### 트러블슈팅 진단 흐름 (Workflow)

현장에서 알 수 없는 힘 제어 에러 또는 이상 거동 발생 시 아래 단계 순으로 진단을 진행하십시오.

1. **F/T 센서 물리 연결 점검:** 센서 본체 커넥터 및 제어기 내부 수신 라인의 LED 상태 확인
2. **소프트웨어 파라미터 검증:** 현재 구동 프로그램 내부의 툴(Tool) 데이터 및 기준 좌표계 할당 번호 재검증
3. **통신 품질 및 로그 확인:** 센서 원시 데이터가 모니터링 창에 출력되는지 확인 후, 제어기 시스템 로그(`Log`) 백업 수행
