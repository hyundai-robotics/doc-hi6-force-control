# 8. 릴리즈 노트 (Release Notes)

힘 제어 기능의 버전별 핵심 변경 사항 및 신규 기능 히스토리입니다.

<br>

## Version: V70.02-00

* **AIDIN F/T 센서 인터페이스(IF) 추가**
  * 에이딘 로보틱스사 센서 라인업의 실시간 통신 프로토콜 정식 지원
* **F/T 센서 오프셋 및 동적 부하 식별 도입**
  * 툴 무게·중심 자동 식별 알고리즘 추가 
* **소프트 스타트 (Soft Start) 기능 적용**
  * 초기 가압 램핑 제어로 초기 접촉 순간의 오버슈트 및 기구 충격 방지
* **실시간 최대 속도 제한 (Vmax) 프로파일 반영**
  * 단차 및 표면 이탈(비접촉) 시 로봇의 급가속 및 제어 발산 차단
* **구조체 형태의 전용 시스템 변수 (_fctrl) 신설**
  * `_fctrl.force_x` 등 직관적 모니터링 변수 제공 (구버전 `cfo` 함수 호환 유지)
