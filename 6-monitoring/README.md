# 6. 모니터링

힘 제어 기능이 진행되는 동안, 로봇의 실시간 거동 상태와 F/T 센서 데이터를 직관적으로 확인하고 진단할 수 있는 모니터링 메뉴입니다. 

실시간 데이터 분석을 통해 제어 파라미터를 최적화하고, 현장 티칭 과정에서 발생할 수 있는 이상 거동을 안전하게 진단할 수 있습니다.


---


##### **모니터링 메뉴 구성**

사용 목적에 따라 총 2가지의 전용 모니터링 화면을 제공합니다. 작업 조건과 디버깅 목적에 맞춰 선택하여 활용하시기 바랍니다.

###### **[힘 데이터 모니터링]**
* **목적:** F/T 센서가 측정하는 날것의 힘(Force)과 토크(Torque) 데이터 자체를 확인하고자 할 때 사용합니다.

* **주요 확인 항목:** 지정된 기준 좌표계 기반의 직교좌표(X, Y, Z, RX, RY, RZ) 현재 힘 데이터를 확입 합니다. 


###### **[힘 모션 모니터링]**
* **목적:** 실시간 가압 상태와 로봇의 추종 거동 및 속도 제약 조건, 접촉 판정 상태를 종합적으로 진단할 수 있습니다.

* **주요 확인 항목:** 실시간 목표 힘(F), 위치 명령(Cmd), 최대 제한 속도(Vmax), 접촉 조건 임계치 매칭 상태(TLT, AVG, HLD)

---

{% hint style="info" %}

**안전 모니터링 수칙:** 신규 공정 튜닝 시에는 반드시 `6.2 힘 모션 모니터링` 창의 **Vmax(최대 제한 속도)** 와 **HLD(지속 시간)** 카운트를 상시 모니터링하여, 로봇이 의도치 않은 발산 진동이나 접촉 판단 누락으로 멈춰 있는지 실시간으로 체크하는 것을 권장합니다.

{% endhint %}
