## 6.2 힘 모션 모니터링

힘 제어 구동 중 실시간으로 인가되는 힘 데이터(F), 제어 명령 위치(Cmd), 그리고 설정된 속도 제한 값(Vmax)의 오차 및 거동 상태를 종합적으로 확인할 수 있는 기능입니다.

<br>

--- 

![](../_assets/_17_fctrl_ctrl_panel_force_motion.png)

#### **화면 구성 항목**

| 항목명 | 설명 |
| :--- | :--- |
| **F** | 실시간 목표 힘 입니다. [단위: N 또는 Nm] |
| **Cmd** | 힘 제어를 추종하기 위해 시스템에서 실시간으로 생성하는 명령 위치입니다. [단위: mm 또는 deg] |
| **Vmax** | 시스템 안정성을 위해 설정된 최대 제한 속도 프로파일 데이터입니다. [단위: mm/s] |
| **TLT** | 접촉 조건 중 **[기울기 각도 임계값]** 상태를 실시간으로 모니터링합니다. |
| **AVG** | 접촉 조건 중 **[각도 변화 임계값]** 상태를 실시간으로 모니터링합니다. |
| **HLD** | 접촉 조건 중 **[지속 시간]** 카운트 수치 및 유지 상태를 모니터링합니다. |

* **좌표계 기준:** 모니터링되는 모든 데이터의 방향 및 축은 힘 제어 조건 설정(`cnd`)에서 지정한 기준 좌표계를 기준으로 정렬됩니다.

* **데이터 갱신 규칙:** 해당 모니터링 창은 힘 제어 구동 명령어(`fctrl on`)가 활성화되어 실시간 제어 루프가 구동 중인 상태에서만 실시간으로 업데이트됩니다.

<br>

--- 

{% hint style="info" %}

**티칭 펜던트(TP) 이동 경로:** [창 조정] ➔ [F1: 선택] ➔ [힘 모션]

**현장 확인 팁:** 초기 접촉 시 로봇 거동이 불안정하다면 우측의 `TLT`, `AVG`, `HLD` 상태 모니터링 데이터를 확인하십시오. 접촉 후 `HLD`(지속 시간)가 목표치까지 채워지지 못하고 리셋된다면, `TLT`나 `AVG` 값이 순간적으로 임계치를 벗어나 접촉 판정이 누락되는 상태이므로 해당 임계 조건을 튜닝해야 합니다.

{% endhint %}
