## 6.1 힘 데이터 모니터링

작업 중 로봇에 가해지는 외력과 토크 데이터를 실시간으로 모니터링할 수 있는 기능입니다. 힘 제어 기능 구동 시 정밀한 인가 상태를 확인하기 위해 필수적으로 참조해야 합니다.

--- 

![](../_assets/_16_fctrl_ctrl_panel_force_data.png)

##### **화면 구성 항목**

| 항목명 | 설명 |
| :--- | :--- |
| **직교좌표 (X, Y, Z, RX, RY, RZ)** | 선택된 기준 좌표계 상에서 로봇 끝단에 작용하는 3축 방향의 힘($\text{N}$) 및 3축 회전 토크($\text{Nm}$) 값입니다. |
| **축좌표 (J1, J2, J3, J4, J5, J6)** | 로봇의 각 관절축(Joint 1 ~ Joint 6)별로 인가되는 물리적인 부하 상태를 실시간으로 환산하여 모니터링하는 항목입니다. |

* **좌표계 기준:** [직교좌표] 데이터의 방향 및 기준축은 힘 제어 조건 설정(`cnd`) 메뉴에서 사용자가 지정한 기준 좌표계를 추종하여 매칭됩니다.

* **데이터 갱신 규칙:** 해당 모니터링 창은 힘 제어 구동 명령어(`fctrl on`)가 활성화되어 제어 루프가 돌고 있는 상태에서만 실시간으로 데이터가 업데이트됩니다.


--- 

{% hint style="info" %}

**티칭 펜던트(TP) 이동 경로:** [창 조정] ➔ [F1: 선택] ➔ [힘 데이터]

**현장 확인 팁:** 로봇 정지 상태에서 데이터가 `0.000` 근처가 아니라면, 자중 보정(Gravity Compensation)이나 센서 제로 세팅(Zeroing)을 확인하십시오.

**출력 기준:** 힘 제어 구동 시 **[직교좌표]** 항목에만 F/T 센서 데이터가 실시간 출력되며, **[축좌표]** 는 `0.0`으로 고정됩니다.

{% endhint %}
