## 2.3 힘 제어 툴 정보

로봇에 장착된 툴의 물리적 특성을 입력하여, 힘 제어 알고리즘의 정확도를 향상시킵니다.  
센서가 인식하는 힘과 토크는 툴 무게 및 중심 좌표에 따라 보정됩니다. 

힘 제어 툴 정보 설정은 아래 경로를 통해 진입할 수 있습니다: 

[F2: 시스템] – 4: 응용파라미터 – 24: 힘제어 – 2: 힘제어 툴 데이터

<br>

---

![](../_assets/_04_fctrl_ctrl_tool_data.png)

| 항목         | 설명 |
|--------------|------|
| **Name**      | 툴 데이터 이름 (자동 입력) |
| **Description** | 툴 설명 또는 용도 (선택 입력) |
| **Weight [kg]** | 툴의 무게. 힘 오차 계산 시 중력 보정에 사용됨 |
| **Center [X, Y, Z]** | 툴의 무게중심 위치 (센서 기준, 단위: mm) |
| **Sensor coordinate** | 센서 기준 좌표계 방향 (UI 오른쪽 그림 참고) |

{% hint style="info" %}
 - 툴 정보는 최대 10개 까지 설정 가능 합니다. 
 - Hi5a에 제공된 센서기반부하추정 기능은 현재 미지원 

{% endhint %}
