#### 2.4.4.2 力控制条件设置 - 运动 - 自动路径生成

设置在力控制操作期间执行的运动控制条件。

本节专门用于配置 **螺旋、双向和锯齿形** 路径和轨迹。


<br>

### **运动类型**

| 项目 |
|----------------|
| **螺旋运动** |
| **双向运动** |
| **锯齿形运动** |

<br>

---

![](../../../_assets/_14_fctrl_ctrl_cnd_motion_raster2.png)

### **螺旋运动**

生成螺旋路径和轨迹的功能。

| 项目 | 描述 |
|--------------|------|
| **速度** | 旋转线速度 (mm/s) |
| **半径** | 最大半径设置 (mm) - 螺旋的最终大小 |
| **旋转次数** | 旋转次数 (rev) - 总旋转计数 |


<br>

---


### **双向运动**
A function that generates a bi-directional path and trajectory.

| 项目 | 描述 |
|--------------|------|
| **速度** | 线性速度 (mm/s) |
| **运动方向** | 运动方向 (+X, -X, +Y, -Y) |
| **运动长度** | 运动长度 (mm) |
| **位移方向** | 位移方向 (+X, -X, +Y, -Y) |
| **位移长度** | 位移 (步距) 长度 (mm) |
| **生成线数** | 在运动方向生成的线数 |

<br>

---

### **锯齿形运动**

A function that generates a zig-zag path and trajectory.

| 项目 | 描述 |
|--------------|------|
| **速度** | 线性速度 (mm/s) |
| **运动方向** | 运动方向 (+X, -X, +Y, -Y) |
| **运动长度** | 运动长度 (mm) |
| **位移方向** | 位移方向 (+X, -X, +Y, -Y) |
| **位移长度** | 位移 (步距) 长度 (mm) |
| **生成线数** | 相对于运动方向生成的线数 |

<br>

---

{% hint style="info" %}

- 此运动基于在 **2.4.1 (力控制条件设置 - 基础)** 中选择的坐标系统相对的 **XY 平面** 生成路径。

{% endhint %}
