### 2.4.3 힘 제어 조건 설정-필터링

힘 센서의 노이즈를 줄이고, 입력값을 안정적으로 제어에 사용할 수 있도록 하기 위한 필터링 기능을 제공합니다.

또한, 일정 힘/토크 범위 내에서 제어 강도를 조절할 수 있는 스케일링 옵션과 

힘 입력에 대한 반응을 더욱 민감하게 하는 바이패스 옵션도 제공합니다. 

<br>

---

![](../../_assets/_08_fctrl_ctrl_cnd_filtering_smooth_force.png)

#### **힘 필터링**

센서의 힘 신호에 대해 **필터** 를 적용하여 흔들림을 제거하고 부드럽게 만듭니다.

| 항목 | 설명 |
|------|------|
| **활성화 여부** | 체크 시 필터 적용 |
| **주파수(Freq)** | 필터 컷오프 주파수 설정 (예: 20 Hz)<br>→ 낮을수록 부드러우나 응답이 느려짐 |

<br>

---

![](../../_assets/_09_fctrl_ctrl_cnd_filtering_smooth_scaling.png)


#### **힘 스케일링**

특정 힘 또는 토크 범위 내에서 제어 강도를 부드럽게 스케일링하는 기능입니다.  
민감도 조정이 필요한 작업에서 유용하며, 보통은 꺼둡니다.

미세한 힘 변화에는 제어를 억제하고, 일정 수준 이상의 힘에만 민감하게 반응하도록 설계가 가능합니다. 

| 항목 | 설명 |
|------|------|
| **활성화 여부** | 체크 시 아래 범위 내에서만 스케일 적용 |
| **Force Range** | 힘 범위 (예: 2 ~ 8 N) |
| **Torque Range** | 토크 범위 (예: 0 ~ 0 Nm) |

![](../../_assets/_11_fctrl_ctrl_cnd_filtering_scaling_graph.png)

{% hint style="info" %}

- 힘 범위 입력시 시작 힘보다 작은 경우 출력 힘은 0으로 출력 되고, 종료 힘 보다 큰 경우 원래 입력된 힘의 값으로 출력된다. 
- 시작 힘과 종료 힘이 같으면 스케일링 기능은 동작 하지 않는다. 

{% endhint %}

<br>

--- 


![](../../_assets/_10_fctrl_ctrl_cnd_filtering_cmd_flow.png)

#### **명령 방식**

로봇에 전달되는 명령 신호 **처리 방식**을 설정합니다.

| 항목 | 설명 |
|------|------|
| **Mode** | Normal: 일반적 명령 전달 방식 <br>Bypass: 민감한 반응을 위한 명령 전달 방식  |
| **Freq** | Bypass 모드에서 사용하는 필터 주파수 설정 (Hz) |

{% hint style="info" %}

- **Bypass** 모드는 **센서 데이터를 즉시 반영**하고자 할 때 사용하며,  
- 매우 민감한 제어가 필요한 실험적 상황에서만 사용 권장됩니다.  
- **소음이나 진동의 위험**이 있으므로 일반 작업에는 **Normal** 모드 사용을 권장합니다.

{% endhint %}

<br> 

--- 

### **설정 가이드**

| 작업 유형        | 권장 설정                   |
|------------------|-----------------------------|
| 폴리싱/샌딩      | Smooth Force = ON, Freq = 20 Hz |
| 부드러운 조립    | Smooth Scaling = ON, 보수적 범위 설정 |
| 고속 반응 / 실험 | Command Flow = Bypass |

---

{% hint style="info" %}

- **필터링**, **스케일링**, **명령 흐름** 설정은 모두 함께 작용하므로, 작업 목적에 따라 **통합적으로 튜닝**해야 합니다.

{% endhint %}
