# 🧩 5. 에러 및 트러블슈팅

센서 기반 힘 제어 기능이 수행되는 동안,  
사용자는 UI를 통해 아래와 같은 **힘 제어 상태 및 예외 상황**을 실시간으로 확인할 수 있습니다.

---

## 힘 제어 예외 상황 및 대응 가이드

| 에러 코드 | 주요 원인 | 가이드 |
|:--:|---|---|
| E0260 | 힘 제어 설정 비활성 | 힘 제어 환경 설정에 On으로 설정 |
| E0353 | 힘 제어 툴 번호 오류 | 힘 제어 툴 번호 설정 |
| E1336 | 사용자 좌표계 번호 오류 | 사용자 좌표계를 설정 및 추가 |
| E0259 | FT 센서 통신 문제 | 센서/케이블 점검 |
| E0272 | 지원되지 않는 센서 | 고객센터 문의(센서 IF 필요) |
| E0273 | FT 센서 통신 문제 | 센서/케이블 점검 |
| E0274 | FT 센서 통신 문제 | 센서/케이블 점검 |


> 모든 예외 상황 발생 시 시스템은 **일시 정지(Safe-Stop)**를 우선 수행합니다.

---

## 트러블슈팅 Workflow

1. FT 센서 연결 상태 점검  
2. 툴 번호, 좌표계 번호 재검증  
3. 센서 모델 지원 여부 확인  
4. 로그 확인 및 백업
