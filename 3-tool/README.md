## 3. 툴 데이터

힘 제어 기능을 사용하기 전 반드시 수행해야 하는 기본 설정입니다. F/T 센서 측정값에서 툴(Tool) 자체의 무게 성분을 제거하여, 환경과 접촉할 때 발생하는 **순수한 힘/토크만 정밀하게 계산**하기 위한 기반이 됩니다.

---

##### 3.1 툴 데이터 설정

로봇 플랜지 종단에 장착된 툴의 물리적 사양을 사용자가 직접 등록하는 단계입니다.

---

##### 3.2 동적 부하 식별 기능 (Dynamic Load Identification)

툴의 정확한 사양을 알기 어려운 경우, 로봇의 자동 모션을 통해 물리 파라미터를 직접 측정하는 기능입니다.
