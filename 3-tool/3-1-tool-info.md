## 3.1 툴 데이터 설정

로봇 플랜지 종단에 장착된 툴의 물리적 사양 및 오프셋 값을 등록하여 힘 제어 알고리즘의 정확도를 향상시키는 단계입니다. 센서가 인식하는 힘과 토크는 설정된 툴 무게 및 중심 값에 따라 실시간으로 보정됩니다.

힘 제어 툴 정보 설정은 아래 경로를 통해 진입할 수 있습니다: 

[F2: 시스템] - 4: 응용파라미터 - 24: 힘제어 - 2: 툴 데이터

---

![](../_assets/_04_fctrl_ctrl_tool_data.png)

##### **[UI 설정 및 상태 표기 항목]**

| 항목         | 설명 |
|--------------|------|
| **이름** | 툴 데이터의 식별 번호 및 이름 (자동 입력) |
| **설명** | 툴에 대한 설명 또는 용도 (선택 입력) |
| **중량 [kg]** | 장착된 툴의 실제 무게. 힘 오차 계산 시 중력 보정의 기준값으로 사용됨 |
| **중심 [X, Y, Z]** | F/T 센서 좌표계 기준의 툴 무게중심 위치 (단위: mm) |
| **힘 영점 [X, Y, Z]** | 툴 장착 상태에서 센서 자체의 초기 힘 오프셋을 상쇄하기 위한 영점 기준값 (단위: N) |
| **토크 영점 [X, Y, Z]** | 툴 장착 상태에서 센서 자체의 초기 토크 오프셋을 상쇄하기 위한 영점 기준값 (단위: Nm) |
| **센서 좌표** | 센서 기준 좌표계의 방향 정의 |
| **동적 부하 식별** | F/T 센서 앞 단에 설치된 툴의 무게와 중심을 추정하는 기능 |

{% hint style="info" %}
 
 - V70.02-00이상 부터 툴 정보는 최대 4개 까지 설정 가능 합니다. 
 - Hi5a에 제공된 센서기반부하추정 기능은, V70.02-00이상 버전 부터 "동적 부하 식별" 기능으로 대체 되었습니다. 

{% endhint %}
