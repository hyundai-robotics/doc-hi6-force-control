## 2.2 F/T 센서 통신 설정

실제 힘 제어(Force Control) 구동 시 제어 루프의 기준이 되는 힘/토크(F/T) 센서와의 실시간 데이터 통신을 활성화하고 연결 파라미터를 설정하는 항목입니다.

[F2: 시스템] ➔ [4: 응용 파라미터] ➔ [24: 힘 제어] ➔ [1: 시스템 환경] ➔ **[통신] 탭 선택**

![](../_assets/_20_fctrl_func_on.png)

---

#### ✓ 주요 설정 항목 가이드

* **기능 사용**
  * 센서 통신 루프의 활성화 여부를 선택합니다. 힘 제어 기능을 사용하려면 반드시 **[유효]** 로 설정해야 합니다.

* **센서 타입 (Sensor Type)**
  * 하드웨어 인터페이스에 매칭되는 F/T 센서 제조사 프로필을 선택합니다. *(※ ATI, OnRobot, Robotiq, AIDIN 등 세부 제어 사양은 하위 매뉴얼 참조)*

* **통신 프로토콜 (Protocol)**
  * 센서 컨트롤러와 로봇 제어기 간의 패킷 송수신 방식을 지정합니다. (`UDP`, `TCP`,`SCI`)

* **바이어스 (Bias)**
  * 센서 초기화 시점의 툴(Tool) 자중 및 기본 잔류 노이즈를 상쇄하기 위한 오프셋 필터 기능입니다.
  * **⚠️ 주의:** 현재 버전에서는 UI 컴포넌트만 배치된 **비활성화(Disabled) 상태**입니다. 추후 지원 가능한 센서 모델에 한하여 순차적으로 기능을 지원할 예정입니다 (향후 버전 릴리즈 노트 참조).

* **네트워크 파라미터 (Network Parameters)**
  * **IP 주소:** F/T 센서 컨트롤러에 할당된 고유 IP 주소를 입력합니다.
  * **로컬 포트 (Local Port):** 로봇 제어기 측에서 센서 데이터를 수신하기 위해 개방하는 포트 번호입니다. (※ 주로 50001, 50100 사용)
  * **원격 포트 (Remote Port):** F/T 센서 측에서 데이터를 송신할 때 사용하는 포트 번호입니다. (※ 센서 제조사 사양서에 명시된 고정 포트 번호 입력)
