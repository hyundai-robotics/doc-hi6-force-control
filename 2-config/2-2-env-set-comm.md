## 2.2 F/T 센서 통신 설정

실제 힘 제어(Force Control) 구동 시 제어 루프의 기준이 되는 힘/토크(F/T) 센서와의 실시간 데이터 통신을 활성화하고 연결 파라미터를 설정하는 항목입니다.

[F2: 시스템] ➔ [4: 응용 파라미터] ➔ [24: 힘 제어] ➔ [1: 시스템 환경] ➔ **[통신] 탭 선택**

---

![](../_assets/_20_fctrl_func_on.png)



##### **[주요 설정 항목 가이드]**

| 설정 항목 | 설명 |
| :--- | :--- |
| **기능 사용** | 힘 제어 루프의 활성화 여부를 선택합니다. 기능을 정상적으로 사용하려면 반드시 **[유효]** 로 설정해야 합니다. |
| **센서 타입 (Sensor Type)** | 하드웨어 인터페이스에 매칭되는 F/T 센서 제조사 프로필을 선택합니다. `(ATI, OnRobot, Robotiq, AIDIN)` |
| **통신 프로토콜 (Protocol)** | 센서 컨트롤러와 로봇 제어기 간의 실시간 데이터 패킷 송수신 방식을 지정합니다. `[UDP]`, `[TCP]`, `[SCI]` 중 선택 가능합니다. |
| **바이어스 (Bias)** | 센서 초기화 시점의 툴 자중 및 잔류 노이즈를 상쇄하기 위한 오프셋 필터입니다.<br>**⚠️ 주의:** 현재 버전에서는 UI 컴포넌트만 배치된 **비활성화(Disabled) 상태**입니다. (추후 순차 지원 예정) |
| **네트워크 파라미터** | • **IP 주소:** F/T 센서 컨트롤러에 할당된 고유 IP 주소를 입력합니다.<br>• **로컬 포트 (Local Port):** 로봇 제어기 측의 데이터 수신 포트 번호입니다. (주로 50001, 50100 사용)<br>• **원격 포트 (Remote Port):** F/T 센서 측의 데이터 송신 포트 번호입니다. (제조사 사양서의 고정 포트 입력) |
