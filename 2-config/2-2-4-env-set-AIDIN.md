## 2.2.4 AIDIN 환경 설정

AIDIN 센서의 설정 방법 및 통신 파라미터는 다음과 같습니다.

---

#### **[기본 통신 파라미터]**

AIDIN 센서를 제어기와 연결하기 위해 아래의 설정을 정확히 입력하십시오.

* **통신 프로토콜:** UDP
* **IP 주소:** 192.168.1.199
* **원격 포트:** 50000

---

#### **AIDIN 센서 설정**

AIDIN 6축 힘/토크 센서 모델을 사용하기 위한 환경 설정 화면입니다. 지정된 IP 주소와 원격 포트 값을 오타 없이 입력한 후 설정을 저장하십시오.

![](../_assets/_21_fctrl_env_set_AIDIN.png)

{% hint style="info" %}

AIDIN 센서는 다른 센서류와 달리 **원격 포트 번호로 `50000`을 사용**합니다. 제어기 기본값이나 타사 센서 포트(49152)를 그대로 사용할 경우 통신이 연결되지 않으므로 주의하십시오.

할당된 고유 IP 주소(`192.168.1.199`)가 제어기 네트워크 대역 내에서 충돌하지 않는지 확인 후 설정을 진행하십시오.

{% endhint %}
