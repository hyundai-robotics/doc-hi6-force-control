## 2 환경 설정

센서 기반 힘 제어 기능을 사용하기 위해 아래의 주요 항목들을 설정해야 합니다. 이 항목들은 제어기 모든 동작의 **기준**이 됩니다.

---

### **설정 메뉴 진입 경로**

힘 제어 환경 설정은 티칭 펜던트의 아래 경로를 통해 진입할 수 있습니다.

> [F2: 시스템] ➔ 4: 응용 파라미터 ➔ 24: 힘 제어 ➔ 1: 시스템 환경 

---

### **기능 사용 여부 설정**

센서 기반 힘 제어 기능의 전체 활성화 여부를 결정합니다. 시스템 내에서 힘 제어 루프를 정상적으로 구동하려면 **반드시 `유효`로 설정**해야 합니다.

* **유효:** 힘 제어 기능 활성화 (실시간 루프 가동)
* **무효:** 힘 제어 기능 비활성화 (일반 위치 제어 모드로 동작)

<br>

**[설정 화면 예시]**

* **기능 비활성화 상태 `무효`**
  
  ![](../_assets/_19_fctrl_func_off.png)

* **기능 활성화 상태 `유효`**
  
  ![](../_assets/_20_fctrl_func_on.png)

<br>

기능 사용 여부를 **`유효`** 로 지정하여 기능을 활성화한 후, 이어서 센서의 통신 정보 및 툴 오프셋(길이) 설정을 진행하십시오.

---

{% hint style="info" %}

**필수 확인 사항**
기능 사용 여부가 `유효`로 변경 및 적용되어야만 후속 센서 파라미터 설정, 통신 연결, 동적 부하 식별(캘리브레이션) 단계를 진행할 수 있습니다.

{% endhint %}
