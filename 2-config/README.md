## 2 환경 설정

센서 기반 힘 제어 기능을 사용하기 위해 아래의 주요 항목들을 설정해야 합니다. 이 항목들은 제어기 모든 동작의 **기준**이 됩니다.

---

##### 설정 메뉴 진입 경로
힘 제어 환경 설정은 아래 경로를 통해 진입할 수 있습니다: 

[F2: 시스템] - 4: 응용파라미터 - 24: 힘제어 - 1: 사용자 환경 설정 ➔ **[통신] 탭 선택**

---

##### **기능 사용 여부 설정**

센서 기반 힘 제어 기능의 활성화 여부를 설정합니다. 힘 제어 기능을 정상적으로 사용하려면 **반드시 '유효'로 설정**해야 합니다.

* **유효:** 기능 활성화
* **무효:** 기능 비활성화

##### **설정 화면 예시**

* **기능 비활성화 상태 (무효)**
  ![기능 무효 설정](../_assets/_19_fctrl_func_off.png)

* **기능 활성화 상태 (유효)**
  ![기능 유효 설정](../_assets/_20_fctrl_func_on.png)


기능 사용 여부를 **'유효'**로 설정한 후, 이어서 센서의 통신 정보와 설치된 오프셋 길이를 설정하십시오.

{% hint style="info" %}

**참고**

기능 사용 여부가 '유효'로 변경되어야 후속 센서 기본 설정 및 캘리브레이션 단계를 진행할 수 있습니다.

{% endhint %}
